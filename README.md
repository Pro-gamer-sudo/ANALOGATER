# ANALOGATER
Open-Lab Project

## PROBLEM STATEMENT

ANALOGATER is designed to implement key
analog operations such as Adder, Subtractor,
Multiplier, Square Rooter, Differentiator,
Integrator.
In many practical applications, fundamental
arithmetic and signal operations need to be
performed efficiently in the analog domain to avoid
delays and errors introduced by digital systems.
Analog circuits provide a fast, continuous, and
reliable approach for such operations.
### OBJECTIVE 
To design, simulate, and implement an accurate
analog circuit system, integrated into a PCB for
stability and performance.

## APPROACH / DESIGN/ METHODOLOGY

1. Circuit Design - Design individual analog circuits
for each operation using operational amplifiers
(Op-Amps) and passive components.
2. Simulation - Simulate the circuits using software
like LTSpice/Proteus to verify accuracy.

3. Breadboard Implementation - Implement the
circuits on a breadboard for initial testing.
4. PCB Design and Fabrication:
• Design a compact and noise-free PCB layout to
integrate all circuits.
• Fabricate and assemble the PCB to ensure robust
hardware implementation.
5. Testing and Validation -Validate the output with
predefined analog signals to ensure correct
functionality and stability.

## RESULTS
1.Adder/Subtractor: Close to accurate output with
minimal voltage offset.
2.Multiplier: Close to correct amplitude scaling
3.Square Rooter: Precise square root estimation.
4.Differentiator: Sharp edge detection and high-frequency
response.
5.Integrator: Smooth integration with minimal drift.
6.Simulation: LTSpice results closely matched practical
outcomes.
7.Bread board Implementation: All circuits (Adder,
Subtractor, Multiplier, Square Rooter, Differentiator, and
Integrator) produced close to accurate outputs with
minimal error, closely matching simulated results.
